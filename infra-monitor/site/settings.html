AUTHENTICATION

SSH 키 관리

Active

SecuWatch 에이전트가 각 서버에 접속할 때 사용하는 SSH Private Key입니다. 이 키로 모든 보호 대상 자산의 monitor 계정에 접속할 수 있습니다.

암호화 방식

RSA 2048-bit

Agent 계정

monitor

등록된 자산

4개

SSH Private Key 다운로드

monitor_rsa.pem (RSA 2048-bit)

REMOTE ACCESS

서버 접속 가이드

다운로드한 SSH 키로 각 보호 대상 서버에 접속하는 방법입니다.

# 키 권한 설정 (최초 1회) chmod 600 monitor_rsa.pem # DB 서버 접속 ssh -i monitor_rsa.pem monitor@172.16.4.10 # Solr 서버 접속 ssh -i monitor_rsa.pem monitor@172.16.3.10 # WAS 서버 접속 ssh -i monitor_rsa.pem monitor@172.16.2.10 # DMZ 서버 접속 ssh -i monitor_rsa.pem monitor@172.16.1.10

SECURITY WARNING

보안 주의사항

Critical
  • 이 SSH 키는 전체 인프라에 대한 접근 권한을 보유합니다
  • 키 파일을 외부에 유출하지 마십시오
  • 분실 시 즉시 보안팀(security@company.com)에 신고
  • 모든 접속 기록은 SIEM에 수집되어 감사됩니다
  • 비인가 사용 시 법적 책임을 물을 수 있습니다
